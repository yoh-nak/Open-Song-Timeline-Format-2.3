# OSTF 2.3.0 release notes (publication candidate)

- Section role and appearance profile using `org.ostf.section-role-appearance.v1`.
- Stable Section/custom Role identities, clip-color references with optional clip IDs.
- Strict standalone UTF-8/JSON acceptance, reference CLI, JSON Schema and semantic validator.
- Conformance examples and negative test cases.
- Known limit: deep Harmony/Melody/Lyrics semantics are opaque and not certified.
- Device-to-device compatibility has not been tested and is not a release prerequisite.
